# iPad 株価チャート・手動売買シミュレーター

## 主な機能

- 日本株・米国株などの株価データを Yahoo Finance 経由で取得
- ローソク足、出来高、移動平均線、RSI を表示
- 日足 / 週足 / 月足を切り替え
- 1足ずつ前後に送るチャートナビゲーション
- 日足の休場日ギャップを除去
- 指定日から開始する手動売買シミュレーション
- シミュレーション開始後は、その日より未来の価格をアプリ全体で非表示
- 「次の取引日へ」で1営業日ずつ進行
- 現物 / 信用、買い / 売り
- 寄り成り / 引け成り / 指値
- 注文は翌取引日に執行
- 現物株数、信用買い株数、信用売り株数を表示
- 確定損益、含み損益、参考純資産を表示
- 注文履歴、約定履歴、CSV保存

## 銘柄コードの例

- トヨタ自動車: `7203.T`
- ソニーグループ: `6758.T`
- Apple: `AAPL`
- Microsoft: `MSFT`

# Streamlit Community CloudでiPadから使う

1. Streamlit Community CloudにGitHubアカウントでサインイン
2. Repository に `Koji2033/Koji2024` を指定
3. Branch は `main`
4. Main file path は `streamlit_app.py`
5. Deploy
6. 発行されたURLをiPadのSafariで開く
7. Safariの共有メニューから「ホーム画面に追加」

既にDeploy済みの場合は、GitHubのmainブランチ更新後にStreamlit側へ反映されます。反映されない場合はアプリを再起動してください。

# 手動売買シミュレーション

## 開始

1. 「手動売買シミュレーション」タブを開く
2. 開始日と初期資金を指定
3. 「シミュレーション開始」

開始すると、その日より後の株価はチャートタブを含めて非表示になります。

週足・月足も、現在までに見えている日足だけから集計します。途中の週・月では、その時点までの暫定足として表示されます。

## 日付を進める

「次の取引日へ」を押すたびに1営業日進みます。

土日祝や休場日は自動的に飛ばします。

## 注文

選択項目:

- 取引区分: 現物 / 信用
- 売買: 買い / 売り
- 株数
- 売買方法: 寄り成り / 引け成り / 指値

注文は現在日の翌取引日にだけ執行判定します。

### 寄り成り

翌取引日の始値で約定します。

### 引け成り

翌取引日の終値で約定します。

### 指値

翌取引日のみ有効です。

買い指値:
- 翌日の始値が指値以下なら始値で約定
- それ以外で安値が指値以下なら指値で約定
- 届かなければ失効

売り指値:
- 翌日の始値が指値以上なら始値で約定
- それ以外で高値が指値以上なら指値で約定
- 届かなければ失効

# ポジション管理

## 現物

現金の範囲内で購入できます。

現物売りは保有株数までです。

## 信用

現時点では簡易モデルです。

信用買いと信用売りを別々に管理し、反対売買を出すと既存の反対建玉を先に返済します。

例:

- 信用売り 300株を保有中
- 信用買い 500株を発注

この場合:

- 300株は信用売り返済
- 残り200株は信用買い新規

になります。

現時点では以下は未実装です。

- 委託保証金率
- 建玉上限
- 信用金利
- 貸株料
- 逆日歩
- 追証
- 強制決済

# Windows PCで起動して同じWi-Fi内のiPadから使う

## 1. Python環境を作る

```text
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

## 2. 起動

`run_windows.bat` をダブルクリックするか、

```text
python -m streamlit run streamlit_app.py
```

を実行します。

## 3. PCのIPアドレスを確認

```text
ipconfig
```

PCが `192.168.1.25` の場合、iPadのSafariで

```text
http://192.168.1.25:8501
```

を開きます。
